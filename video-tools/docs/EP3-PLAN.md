## 画面のルール（2026-11-18 23:20 本人と確定）
- **1カットに主役1人**。主役の名札＝投票チップ（A青・B茶・C緑）＋名前＋@ID（PWAと同じクリーム地＋濃い枠）
- **本人のコメントは本人の吹き出しにそのまま**。こちらが作ったセリフは文章にしない（演技・「！？」・下の結果文で表す）
- **前の主役のカットに、次の主役が歩いて来て自分のコメントを言う** → そのまま次の主役に（つなぎ目＝話の流れ）
- 下は「何をしたか（白・大）」→「どうなったか（黄）」の縁取り文字2行だけ。字幕の箱は使わない
- **黄色の結果文は、結果が画面で分かった瞬間に出す**（例：魚が1匹だけ上がったコマ）。それまでは白のアクション名だけ。ナレーションも同じタイミング
- 名札の出し方：
  - 今回コメントした人＝小さな名札（色の点＋名前、半透明）。ただし画面に5人以上いる引きの画では出さない
  - コメントしていない人＝名札なし
  - 主役だけ大きな名札
- Reels の安全域：下から約20%（y>1520）と右端150px には文字を置かない
- 上の看板は毎カット共通「コメントで動く無人島　◯日目」（仮）
- 読む時間：カットの長さ ≥ 文字数÷8＋1秒
- 「C」「Ｃで！」だけの人はまとめて1カットに並べる
- **「◯日目」は暦の日付ではなく、動画を出すたびに1つ進む**（動画1本＝島の1日）
- 表紙：中央に黄色の「◯日目」＋看板＋一言の結果。ギャラリーの3:4切り抜き（y 240〜1680）に収める

## PWA：行方不明（2026-11-19 追加）
名簿（islanders）の人に `missing` を付けると、その日から地図の姿が消え、森の奥に「？」と足跡が出る。名前で検索して開くと「いま・行方不明」と文が出る。
```json
{ "id": "yuradayo0330", "name": "ゆら", ..., "missing": { "day": 3, "text": "森の奥へ探検に行ったまま、戻ってこない…" } }
```
- `day`：この日（島の◯日目）から有効。`x`/`z` で「？」の位置を変えられる（既定は森の奥 -128, -34）
- 見つかったら `"found": true` にするか、`missing` を消す
- **3日目の投稿の瞬間に、Muse が Firebase の islanders のゆらさんに付ける**
