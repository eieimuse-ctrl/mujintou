## スクリプトの処理手順（compose_ep2.py）
1. `video/build/ep2/comp/plates/` にプレートPNGを生成（冪等：既存なら作り直さない）。
2. ffmpeg：3セグメントを concat フィルタで連結 → プレートを overlay 連鎖 → 音声は adelay で配置した m1〜m7 と BGM を amix。
   色は bt709 のまま（セグメント生成時に変換済み）。映像は libx264。
3. 出力（スクリプト実行時の成果物）：
   - `video/out/ep2_master.mkv`（CRF 16）
   - `video/out/ep2_post.mp4`（CRF 22、100MB以下、faststart、AAC 192k）
   - `video/out/ep2_preview.mp4`（780×1688、CRF 26）
4. 最後に ffprobe で尺・解像度・音声の有無を検証し、結果を標準出力に出す。
5. 途中状態は `video/build/ep2/comp/` の下に残し、再実行で続きから進める冪等な作りにする。
