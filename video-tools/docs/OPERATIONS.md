## 3. ルール
### 投票
- 質問は **3択＋D（自由に提案）**。A・B・C・D の一文字で参加できる気軽さを優先（自由記述だけの回はコメントが減った）
- 採用は **コメントの件数が一番多い案**。D が一番多いときは、D の中で **いいねが一番多い案**。同数のときは先に書かれたもの
- 1人1票。同じ人が何度もコメントしたら最後のコメントを数える
- 締め切りは動画に出さない
- 選択肢には「やると何が起きるか（ご褒美）」を付ける。どの案を選んでも島に何かが残るようにする
- どの案も「正解」に見せない。どの案にも良い点と足りない点を描く

### コメントの扱い
- 本人のコメントは **そのまま** 本人の吹き出しに出す。40字を超えるものは本人の言葉のまま要点を抜き出して「…」でつなぐ（言葉を足さない）
- こちらが作ったセリフを、本人の言葉として出さない（演技・「！？」・下の結果文で表す）
- 採用された案だけでなく、コメントした人がそれぞれ「やってみる」場面を作る。突飛な案も1枠拾う
- 名前と @ID はそのまま。装飾文字の名前は普通の文字にして出す

### 動画の作り方
- 長さは **45〜50秒**。冒頭2秒で何の動画か分かるように（スキップ率が約6割のため）
- **最初の8秒以内に「フォローすると次の動画で流れ着く」と「島はプロフィールのリンクから」**（プロフィール画面のボタンとリンクに輪を出す）
- 本筋は1本、寄り道は1〜2個まで
- 動きを入れる：引きで進む画（カメラがついていく）、木が倒れる、建物が組み上がる（台本の props3d：tree・logs・build）。毎回、島に残る変化を1つ作る
- 1カットに主役1人。主役は大きな名札（名前＋@ID、3択の回は投票の色チップ A青・B茶・C緑）。今回コメントした人は小さな名札。5人以上の引きの画では小さな名札を出さない
- 下の文字は「何をしたか（白・大）」→「どうなったか（黄）」。黄色は結果が画面で分かった瞬間に出す
- Reels の安全域：下から約20%（y>1520）と右端150px に文字を置かない
- 上の看板「コメントで動く無人島　◯日目」。表紙は中央に黄色の「◯日目」＋一言（ギャラリーで3:4に切り抜かれても収まる）
- ナレーションは画面の文の読み上げではなく、場面に合わせた短い要約。VOICEVOX 春日部つむぎ（speaker 8）、速さ 1.15。次の文や場面の終わりにはみ出さない（compose.py が測って最大1.3倍速）
- BGM：「Beachfront Celebration」Kevin MacLeod（CC BY 4.0）。**キャプションにクレジット必須**
- 「◯日目」は暦ではなく、動画を出すたびに1つ進む（動画1本＝島の1日）
- 動画は 100MB 未満（compose.py が自動で収める）
- 他の人のキャラクター・作品は出さない

### このプロジェクトの強み
**動画に出なくても、リンクを開けば自分の島民が島で暮らしている**。毎回、冒頭・途中・締めで伝える。PWA で「答え合わせ」や「続き」が見られるようにする（例：行方不明者の正体は PWA で「？」をタップすると分かった）。

### 友達紹介（4日目から）
- コメントで友達を **@タグ付け** すると、島でその人と「仲良し」になる（名簿の `relationships` に `friend`。PWA の詳細の「関係」に出る）
- まだ島にいない友達は、フォローして島民になった日に関係を足す（`ep5/input/pending_friends.json`）
- 次の動画で、仲良しになったペアが並んで登場する

## 4. PWA で使える仕組み
| 仕組み | 書き方 | 見え方 |
|---|---|---|
| きょうの行動 | 名簿の人に `today`（`pwa_patch.py` が作る） | 次の動画までその場所でその動き。「いま・きょうの行動」 |
| 行方不明 | 名簿の人に `missing` | 姿が消え、森の奥に「？」と焚き火の光。「？」をタップすると本人が分かる |
| 森の道 | state に `forestRoad`（`open: true` で開通） | 道のマスの木が消える。島のいまに進み具合 |
| 火の番 | 森の道があると自動 | 島民が松明を持って道に立つ（5人で1時間ごとに交代）。詳細に「火の番 森の道の◯本目」 |
| 建物 | state の `buildings`（hut・field・pier・watchtower・still〔蒸留装置〕・ruins〔昔の住人の跡〕） | 島に建つ。動画の島にも映る |
| 行動範囲 | state の `districts` | 範囲が広がると年表に自動で入る |
| 関係 | 名簿の人に `relationships` | 詳細の「関係」に出る |

**座標の注意**：state.json に `"map"` が無いため、`base` と `buildings` の x・z は **ワールド座標の1/3** で書く。`forestRoad.points`・`today`・`missing` はワールド座標のまま。

## 5. 制作ツールの注意（壊さないこと）
- `compose.py` のナレーションは **atempo → adelay の順**（逆にすると開始位置まで縮んで、前のセリフに重なる）
- 録画中は外へ通信しない（台本の名簿だけで撮る＝誰が作っても同じ動画）
- 合成のたびに `out/<名前>_manifest.json` が出る。Claude と Muse の入力が同じか照合できる
