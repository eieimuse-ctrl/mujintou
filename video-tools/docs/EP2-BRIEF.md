# 2日目 アニメーション制作ブリーフ（2026-11-18 16:00・Opus向け）

## 目的
2日目の動画（約45秒、1080×1920）を「アニメーション」として作る。PWAの画面録画ではない。
本家 @minna_mujintou のような、動画専用の世界で出来事をシーンとして描く方式。
住民は2Dドット絵のまま（3D化しない）。PWAのUI（タブ・チップ・ボタン・検索画面）は島のシーンに一切出さない。
唯一の例外は冒頭フックのスマホ画面（プロフィールのリンクから島を開く所）だけ。

## 最初に読むもの
- video/FABLE_BUILD.md（特に v3 の節：手動ステップ録画 fable_rec_v3 / timeline の方式）
- video/EP2-SCRIPT.md（確定台本。ナレーション文と構成）
- site/js/data.js / site/js/config.js（RTDB読みとJSONフォールバックの仕組み）
- site/js/drift.js（漂流者の配置・漂い表現）

## シーン構成（目安45秒）
1. 0–5s フック：スマホでプロフィールのリンクから島を開く画面。現在の day=2 状態（島民52人）を v3_ui_hd の方式でHD再撮影。ナレーション m1
2. 5–13s 1日目の早回し回想：video/build/rec3 の1日目テイク（a/b2/c）の再利用可。ナレーション m2
3. 13–22s 漂着：浜の沖で52人が漂流者として漂い、浜へ流れ着く。ナレーション m3
   - ステージ用に video/stage2/ へ site のコピーを作り、そのコピーのデータでは52人を drifters・islanders 空にする
   - コピー側では RTDB を無効化し、ローカルJSONだけ読ませる（data.js/config.js のフォールバック挙動を使う）
   - 録画は fable_rec_v3 の手動ステップ方式（決定的・再開可能）
4. 22–30s 拠点決定：平原の広場を見せる。ナレーション m4
5. 30–38s 集合と個人カット：島民が平原の拠点へ集まる様子。島のシーンは day=2 の実データのコピーで撮る。
   個人カットは さか（sakasaka_1482、島民1号・最多いいね）の名前入りクローズアップを必須とし、余裕があればもう1〜2人。ナレーション m5
6. 38–41s 結果：拠点のある島の全景（BGMのみ、または m5 の尾）
7. 質問＋締め：本人の選択待ち。
   - このステップに到達した時点で video/audio/m6.wav が存在すれば、質問セグメント（選択肢プレート＋m6）＋締め（m7、「2日目」表記）までレンダリングする
   - 存在しなければ、そこまでの本編を完成させ、質問セグメントだけ後から10分以内に足せる状態（プロジェクトファイルと手順メモ）で納品する
